# ⚛️ My Frontend Toolkit (React / TypeScript / Vite)

Boîte à outils modulaire d'architecture frontend prête pour la production. Chaque module est isolé, typé en **TypeScript**, documenté (`NOTES.md`) et validé par des tests unitaires (**Vitest / React Testing Library**).

## 📦 Catalogue des 10 Modules

Retrouvez l'intégralité du tableau récapitulatif (de `01-env-config` avec Zod jusqu'à `10-docker-nginx-deploy` avec Docker/Nginx, en passant par l'authentification RBAC, TanStack Query, les WebSockets et les interceptors Axios) dans le dépôt source.

## 🚀 Installation & Exécution des Tests

```bash
git clone https://github.com/Madoumssow/my-frontend-toolkit.git
cd my-frontend-toolkit
npm install
npm test
```

## 📖 Réutilisation

Copiez le dossier du module souhaité (ex. `src/02-http-client-interceptors/`) et référez-vous au fichier **`NOTES.md`** local pour les instructions d'intégration.
