# ⚛️ My Frontend Toolkit (React / TypeScript / Vite)

Boîte à outils modulaire d'architecture frontend (React, TypeScript, Vite, Vitest, Docker) regroupant 10 modules prêts pour la production (configuration `.env`, client HTTP avec rafraîchissement JWT, ErrorBoundary, routage RBAC, formulaires Zod, TanStack Query, hooks personnalisés, modales/toasts, WebSockets et déploiement Nginx).

*Le contenu complet du fichier `README.md` (incluant le catalogue des modules, les commandes d'installation et d'exécution des tests) peut être remplacé par la documentation détaillée de votre boîte à outils.*
